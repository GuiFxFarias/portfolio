# Guilherme Farias — Portfolio

Personal résumé/portfolio: a single page in plain HTML/CSS/JS (no build step, no dependencies).

## Publish on GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under "Build and deployment", select **Source: Deploy from a branch**.
3. Branch: `main`, folder `/ (root)`.
4. Save — the page will be live at `https://guifxfarias.github.io/portfolio/` within a few minutes.
