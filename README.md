# Guilherme Farias — Portfólio

Currículo/portfólio pessoal, página única em HTML/CSS/JS puro (sem build, sem dependências).

## Publicar no GitHub Pages

1. Vá em **Settings → Pages** neste repositório.
2. Em "Build and deployment", selecione **Source: Deploy from a branch**.
3. Branch: `main`, pasta `/ (root)`.
4. Salve — a página fica disponível em `https://guifxfarias.github.io/portfolio/` em alguns minutos.
